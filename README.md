# Oncle G Livraisons - Plateforme de Livraison Moderne à Brazzaville

Oncle G Livraisons est une plateforme de livraison express innovante basée à Brazzaville, offrant une gamme complète de services de livraison rapides et fiables. Notre mission est de simplifier la vie des habitants de Brazzaville en leur offrant des services de proximité avec le sourire.

## Structure du Site

### Pages Principales
- `index.html` - Page d'accueil avec présentation des services
- `pages/a-propos.html` - Informations sur l'entreprise et nos valeurs
- `pages/commandez-en-un-geste.html` - Interface de commande simplifiée
- `pages/communaute.html` - Espace communautaire et témoignages
- `pages/contacts.html` - Formulaire de contact et coordonnées
- `pages/employer.html` - Page de recrutement et opportunités d'emploi
- `pages/livraison-express.html` - Détails sur le service de livraison express

### Services Oncle G
- `pages/oncle-g/Allô'Gaz.html` - Service de livraison de gaz à domicile
- `pages/oncle-g/Allô’Gaz.html` - Version alternative du service de gaz
- `pages/oncle-g/ConciergerieExpress.html` - Service de conciergerie à domicile
- `pages/oncle-g/G-PROMarketing.html` - Solution e-commerce clé en main
- `pages/oncle-g/pro-g.html` - Service de livraison professionnelle illimitée

## Technologies Modernes Utilisées

### Frameworks et Bibliothèques
- **Tailwind CSS** - Framework CSS utilitaire pour un développement rapide et responsive
- **Alpine.js** - Bibliothèque JavaScript légère pour l'interaction utilisateur
- **Lottie** - Animation vectorielle pour des expériences riches
- **Google Fonts** - Typographie moderne et optimisée

### Optimisations de Performance
- **Images optimisées** - Formats WebP et chargement différé pour une vitesse maximale
- **CSS asynchrone** - Chargement non-bloquant pour une expérience utilisateur fluide
- **Préchargement de ressources critiques** - Amélioration du temps de chargement initial
- **Animations légères** - Utilisation d'animations optimisées pour la performance

### SEO Avancé
- **Balises Open Graph complètes** - Optimisation pour le partage sur les réseaux sociaux
- **Balises Twitter Cards** - Présentation optimisée sur Twitter
- **Données structurées** - Intégration de schémas JSON-LD pour un meilleur référencement
- **Balises canoniques** - Gestion des contenus dupliqués
- **Méta-balises géographiques** - Ciblage local pour Brazzaville

### Accessibilité
- **Balises sémantiques HTML5** - Structure claire pour les lecteurs d'écran
- **Attributs ARIA** - Amélioration de l'accessibilité pour les utilisateurs malvoyants
- **Navigation clavier** - Accès complet aux fonctionnalités sans souris
- **Contrastes de couleurs optimisés** - Respect des normes WCAG

### Design Responsif
- **Design mobile-first** - Expérience optimisée pour tous les appareils
- **Grilles flexibles** - Adaptation automatique aux différentes tailles d'écran
- **Interactions tactiles optimisées** - Boutons et éléments adaptés aux écrans tactiles
